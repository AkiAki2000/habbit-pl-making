# 習慣PL

1つの習慣科目（デフォルト「睡眠」）を、日々の達成度を損益（円）に換算して記録するシンプルなWebアプリです。

## できること

- 「達成」「未達」「大きく未達」の3択でその日の記録をつける
  - 達成: +100円 / 未達: 0円 / 大きく未達: -100円
- 記録した日付ごとの履歴を一覧表示
- 直近の合計損益を画面上部に表示

データはブラウザのローカルストレージにのみ保存されます（サーバー・DBなし）。

## 開発

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) を開いてください。

## 技術構成

- Next.js (App Router) + TypeScript
- Tailwind CSS
- 状態保存: localStorage
