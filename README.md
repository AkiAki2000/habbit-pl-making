# 習慣PL

複数の習慣科目（例: 睡眠、トレーニング・運動、深酒、たばこ）を、日々の達成度を損益（円）に換算して記録するシンプルなWebアプリです。

## できること

- 習慣科目を好きなだけ登録・編集（削除も可）
- 科目ごとに「達成」「未達」「大きく未達」の換算金額を個別に設定
- その日ある科目をまとめて記録（各科目3択ボタン）
- 週の始まり（月曜）から今日までの週次損益と、累計損益を画面上部に表示
- 記録した日付ごとの履歴を一覧表示（科目・評価・金額）

データはブラウザのローカルストレージにのみ保存されます（サーバー・DBなし）。
以前の単一科目版のデータがある場合は、初回起動時に自動で移行されます。

## 開発

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) を開いてください。

## 技術構成

- Next.js (App Router) + TypeScript
- Tailwind CSS
- 状態保存: localStorage
