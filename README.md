# habbit-pl-making — 外食チェーン株価・IRトラッカー

外食チェーン24社の株価を毎朝自動取得し、Webダッシュボードで株価推移・時価総額・IR（適時開示）履歴を確認できるプロジェクトです。

## 全体構成

```
docs/                    GitHub Pages で公開する静的ダッシュボード（このフォルダがそのままサイトになる）
  index.html / app.js / style.css
  companies.json         追跡銘柄マスタ（コード・銘柄名・ブランド・発行済株式数）
  data/prices/{code}.json  日次の終値・時価総額の履歴
  data/ir/{code}.json      IR（適時開示）イベントのログ
  data/status.json         直近の自動取得結果（成功・エラー）
scripts/
  fetch_prices.py         毎朝実行：最新終値と（可能なら）発行済株式数を自動取得し記録
  backfill_prices.py      過去分をまとめて取得（デフォルト2026-01-01〜今日）
  add_ir_event.py         IRイベントを1件手動登録するCLI
  common.py               共通の読み書きヘルパー
.github/workflows/
  fetch-daily.yml          平日朝7時(JST)に自動実行し、データをコミット
  backfill.yml             手動実行（Actionsタブから）でバックフィル
```

## 使い方

### 1. GitHub Pages を有効化する

リポジトリの Settings → Pages で「Deploy from a branch」→ ブランチ: このブランチ（またはmainにマージ後）/ フォルダ: `/docs` を選択してください。有効化すると `https://<ユーザー名>.github.io/<リポジトリ名>/` でダッシュボードが見られます。

### 2. 毎朝の自動取得

`.github/workflows/fetch-daily.yml` が平日朝7時(JST)に自動実行され、`docs/data/` を更新して自動コミット・プッシュします。Pages は自動で再デプロイされます。手動で今すぐ実行したい場合は GitHub の Actions タブ → 「毎朝の株価取得」→ Run workflow。

### 3. 過去分のバックフィル（2026年1月〜）

Actions タブ → 「株価バックフィル（手動実行）」→ Run workflow。開始日はデフォルトで `2026-01-01` です。1社だけやり直したい場合は証券コードを指定してください。

データソースは Yahoo Finance の非公式チャートAPI（`yfinance` ライブラリ経由）です。このセッションのサンドボックス環境は外部ネットワークが制限されておりここでは実行・検証できませんでしたが、GitHub Actions のランナーは通常のインターネットアクセスを持つため、そちらで正常に動作するはずです。初回はバックフィルワークフローを実行してデータを埋めてください。

### 4. 発行済株式数（時価総額の計算に必要）

`fetch_prices.py` は毎朝 Yahoo Finance から発行済株式数の自動取得を試みます（`shares_outstanding_source: "auto (yfinance)"`）。日本株はこの値が取得できない・古いことがあるため、取れなかった銘柄は `docs/companies.json` の `shares_outstanding` を四半期決算短信や有価証券報告書の値で手動更新してください。

自動取得値が前回と変わった場合は「株式数変更」として自動的にIRログへ記録されるので、自社株買いや株式分割などの動きに気づきやすくなっています（実際の開示内容を確認してnoteを補完することを推奨）。

### 5. IR履歴の記録

```
python scripts/add_ir_event.py --code 3563 --date 2026-04-10 \
  --category 決算 --title "2026年2月期 通期決算を発表" \
  --url "https://www.foodlife.co.jp/ir/..." \
  --note "経常利益は前期比+8%"
```

category の例: 決算 / 業績修正 / 配当 / 株主優待 / 自己株式取得 / 株式分割 / M&A・提携 / その他適時開示

2026年1月以降の過去分を遡って記録したい場合、各社のIRサイトやTDnet（適時開示情報閲覧サービース）を確認しながら本コマンドで追加していく運用を想定しています。信頼性の観点から、実在しない開示内容を自動生成することは避け、実際の開示資料を確認しながら登録することを推奨します。

## ローカルで確認する

```
cd docs && python3 -m http.server 8000
```

`http://localhost:8000` を開くと、`docs/data/` にあるJSONをそのまま読み込んで表示します（初回・データ未取得時は「データがありません」と表示されます）。

## 既知の制約

- 株価データソース（Yahoo Financeの非公式API）は仕様変更で取得できなくなる可能性があります。`docs/data/status.json` にエラーが記録されるので、ダッシュボード上部の状態表示で気づけます。
- バックフィルした日付の時価総額は、その日時点の実際の発行済株式数ではなく現在値を使った概算です（`shares_estimated: true` で明示）。正確な推移が必要な場合は、IR履歴を参照しながら `docs/data/prices/{code}.json` を手動で補正してください。
- IR履歴は自動収集していません（TDnet等の網羅的な自動取得は未実装）。株式数変化の自動検知に加え、`add_ir_event.py` での手動記録を基本としています。
